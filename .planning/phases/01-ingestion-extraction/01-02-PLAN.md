<task type="auto">
  <name>Task 1: Implement GROBID client + settings</name>
  <files>backend/grobid_client.py, backend/settings.py</files>
  <action>
    Create `backend/grobid_client.py` with a function like `extract_tei(pdf_path)`
    that:
    - Posts the PDF to `{GROBID_URL}/api/processFulltextDocument`.
    - Uses `requests.post` with multipart form data and a timeout setting.
    - Returns TEI/XML text and raises a clear exception on non-200 responses.

    Add settings to `backend/settings.py`:
    - `GROBID_URL` defaulting to `http://localhost:8070`.
    - `GROBID_TIMEOUT` (seconds) defaulting to a safe value (ex: 120).
  </action>
  <verify>python -c "from backend.grobid_client import extract_tei; print(extract_tei)"</verify>
  <done>GROBID client exists and uses configurable URL/timeout settings.</done>
</task>

<task type="auto">
  <name>Task 2: Parse TEI for metadata and citations</name>
  <files>backend/extraction.py</files>
  <action>
    Create `backend/extraction.py` with helpers to parse TEI/XML using `lxml`:
    - `parse_metadata(tei_root)` returns title, authors (list), year, and raw
      journal/container fields when available.
    - `parse_citations(tei_root)` returns in-text citation callouts with their
      target IDs and surrounding sentence text.
    - `parse_bibliography(tei_root)` returns bibliography entries with raw
      reference text and any DOI/URL present in the TEI.
    - `parse_tei(tei_xml)` returns a dict with `metadata`, `citations`,
      `references`, and `extraction_version`.
    Keep raw reference strings to support manual review later.
  </action>
  <verify>python -c "from backend.extraction import parse_tei; print(parse_tei)"</verify>
  <done>TEI parsing returns structured metadata, citations, and bibliography entries.</done>
</task>

<task type="auto">
  <name>Task 3: Wire extraction into ingestion records</name>
  <files>backend/ingestion_store.py, backend/schemas.py, backend/main.py</files>
  <action>
    Extend ingestion storage to persist extraction artifacts:
    - Save TEI/XML to `{doc_id}/extraction/tei.xml`.
    - Store extraction payload under `metadata.json` as
      `extraction: { status, extracted_at, data }`.

    Add schemas for extraction responses (ex: `ExtractionResult`,
    `ExtractionResponse`) in `backend/schemas.py`.

    Add endpoints in `backend/main.py`:
    - `POST /ingest/{doc_id}/extract` runs GROBID, parses TEI, stores results,
      and returns the extraction payload.
    - `GET /ingest/{doc_id}/extraction` returns the stored extraction payload.
    Return 404 if the document ID is unknown and 500 on extraction errors.
  </action>
  <verify>curl -X POST http://localhost:8000/ingest/{doc_id}/extract</verify>
  <done>Extraction endpoints persist TEI and metadata/citation payloads per document.</done>
</task>
