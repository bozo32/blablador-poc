<task type="auto">
  <name>Task 1: Implement Crossref reference resolver</name>
  <files>backend/reference_resolver.py, backend/settings.py, backend/schemas.py</files>
  <action>
    Create `backend/reference_resolver.py` with a `resolve_references` helper that:
    - Accepts bibliography entries from extraction (raw reference string + any DOI).
    - Uses Crossref REST API `GET /works` with `query.bibliographic` when DOI
      is missing, and pulls the top item + score.
    - Includes `mailto=CROSSREF_MAILTO` on requests and applies light throttling
      (sleep between requests) to avoid rate limits.
    - Returns normalized results with fields: `reference_id`, `raw`, `doi`,
      `title`, `publisher`, `year`, `source`, `confidence`.

    Add `CROSSREF_MAILTO` (and optional `CROSSREF_API_URL`) to settings and add
    `ResolvedReference` schema to `backend/schemas.py`.
  </action>
  <verify>python -c "from backend.reference_resolver import resolve_references; print(resolve_references)"</verify>
  <done>Reference resolver returns normalized Crossref metadata with confidence.</done>
</task>

<task type="auto">
  <name>Task 2: Store and expose resolution results</name>
  <files>backend/ingestion_store.py, backend/main.py, backend/schemas.py</files>
  <action>
    Extend ingestion storage to persist resolution payloads under
    `resolution: { status, resolved_at, data }` in `metadata.json`.

    Add an endpoint in `backend/main.py`:
    - `POST /ingest/{doc_id}/resolve` loads extracted references, runs the
      resolver, stores results, and returns the resolution payload.
    - `GET /ingest/{doc_id}/resolution` returns stored resolution data.

    Return 404 for missing documents or extraction data, and 500 for resolver
    failures with a clear error message.
  </action>
  <verify>curl -X POST http://localhost:8000/ingest/{doc_id}/resolve</verify>
  <done>Resolution payloads are stored and retrievable per document.</done>
</task>
