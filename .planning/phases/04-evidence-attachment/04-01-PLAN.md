  <action>
Create backend support that compiles resolver outputs and bibliographic metadata into a single retrieval dossier payload.

- Add `backend/reference_retrieval.py` with helpers to load ingestion metadata, GROBID references, and resolution records (Crossref/OpenAlex) for a given `doc_id` + `reference_id`. Compose a structured dictionary containing: canonical citation string (APA-short), DOI/URL, publisher PDF URL when available, resolver confidence, and fallback instructions when links are missing.
- Extend `backend/schemas.py` with `ReferenceRetrievalSource` + `ReferenceRetrievalResponse` Pydantic models so the FastAPI route returns typed responses.
- Register `GET /references/{doc_id}/{reference_id}/retrieval` in `backend/main.py`, reusing `ingestion_store` helpers for disk I/O and returning 404 when data is missing. Ensure the route avoids slow network calls by relying on cached resolver payloads generated in Phase 1/2.
- Write `tests/test_reference_retrieval.py` to cover: (1) happy path merging DOI + publisher URL, (2) missing DOI fallback that emits manual instructions sourced from bibliography text, and (3) serialization of resolver confidence values.
  </action>
  <verify>pytest tests/test_reference_retrieval.py</verify>
