Update `backend/tei_body.py` to add a deterministic fallback that triggers when TEI sentence boundaries are suspicious.

Implementation constraints:
- Keep public API: `build_document_body(tei_xml)` returns the same shape: `{"paragraphs": [{"paragraph_id", "sentences": [{"sentence_id", "segments", "citation_indices"}]}]}`.
- Add a helper (inside the module) that:
  1) Builds a paragraph-level `segments` list (text/citation) using the existing `walk()` logic.
  2) Flattens segments to a token stream where citations are placeholders (e.g., `__CITE_0__`).
  3) Splits into sentence strings using a conservative regex heuristic (split on `.?!` followed by whitespace, avoiding empty fragments).
  4) Rehydrates each sentence into a `segments` list, replacing placeholders with the original citation segment dicts.
  5) Assigns a stable generated `sentence_id` per fallback sentence (deterministic from `paragraph_id` + index + a short hash of the sentence text).
  6) Ensures citation segments in fallback sentences get `sentence_id` set to that generated id.

Suspicious detection (simple + explicit, do not overfit): trigger fallback when either:
- a paragraph has TEI `<s>` nodes but any sentence’s flattened text length exceeds 480 chars, OR
- a paragraph has exactly 1 TEI `<s>` node and flattened paragraph text length exceeds 600 chars.

Avoid new dependencies; use stdlib only.
