- In `enqueue_processing(attachment_id)`, check global pause.

  - In `trigger_auto_rerun(...)`, if paused, return a response shaped like `request_rerun` but with `status="queued"` and `position` reflecting queueing; do not start workers.
  - Ensure queued auto jobs start after unpausing (on next manual rerun or next request) by calling the existing dequeue logic.

Do NOT change existing response models.
  </action>
