<task type="auto">
  <name>Implement Source bin backend integration in attachment_queue</name>
  <files>frontend/attachment_queue.py, frontend/assets/attachment_panel.css</files>
  <action>
Refactor `frontend/attachment_queue.py` so it can act as a global Source bin:

- Upload behavior:
  - When files are added to the bin, immediately POST each file’s metadata to `POST /attachments` (global upload) so backend processing starts right away.
  - Keep the local temp file path for local-only operations (e.g., opening the PDF on the developer machine).
  - Implement dedupe: if a new upload matches an existing item by `(filename, size)` and the existing item is not archived, do not enqueue a duplicate.

- Placement behavior:
  - Allow items to have `claim_id=None` until placed.
  - Implement strict auto-placement: only auto-place when confidence >= 0.90 using existing `claim_queue.auto_match_claim` candidates.
  - When placing/re-placing, call `PATCH /attachments/{attachment_id}` to set `claim_id`, `doc_id`, `citation_index`, `target_id` (when known) and log timeline.
  - When placement happens and the claim has text, auto-trigger evidence rerun by calling `POST /claims/{claim_id}/evidence/rerun` with note `auto-placement`.

- Archive behavior:
  - Add archive/unarchive helpers that call `PATCH /attachments/{attachment_id}` with `archived=true|false`.
  - Archived items hidden by default; add a `show_archived` session flag.

- Status presentation:
  - Track backend statuses via `GET /attachments` (global list) and per-item `GET /attachments/{id}` when needed.
  - Add a “bulk retry” helper calling `POST /attachments/{id}/retry` for failed items.
  - Do not use toasts/popups; status changes are visible via colored pills/progress.

Update `frontend/assets/attachment_panel.css` to support Source bin list rows, status colors, and a progress bar (use `st.progress` in UI; CSS handles badges).
  </action>
  <verify>python -m py_compile frontend/attachment_queue.py</verify>
  <done>Source bin state can upload unassigned items, sync from backend `/attachments`, and support place/re-place + archive + retry.</done>

1) Update `frontend/ui.py`:
- Remove the old per-claim attachment workspace rendering (no dropzones on claim cards).

  - Shows a recency list with status colors: not started (empty), processing (orange), processed but not placed (yellow), processed+placed (green), failed (red).
  - Offers per-item actions: View PDF, Assign/Re-place, Retry, Archive.

- In `frontend/ui.py` and/or `frontend/evidence_store.py`, disable evidence selection controls while backend `lock_state.locked == True`.
