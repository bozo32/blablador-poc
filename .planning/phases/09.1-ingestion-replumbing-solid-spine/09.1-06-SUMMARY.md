# Phase 9.1 Plan 06: Dev Scripts + README + Verification Checkpoint Summary

**Added thin dev scripts and updated README so a fresh machine can boot the full Compose stack and prove the ingestion spine works end-to-end.**

## Accomplishments

- Added `scripts/dev/up.sh` to boot Compose and print service URLs
- Added `scripts/dev/down.sh` to tear down the stack (explicitly removes volumes)
- Added `scripts/dev/smoke_ingest.sh` to upload a PDF, trigger extraction, and fetch `/ingest/{doc_id}` without jq
- Updated `README.md` with a Compose quickstart and smoke flow

## Verification

- `bash scripts/dev/up.sh`
- `bash scripts/dev/smoke_ingest.sh fixtures/sample.pdf`
- UI loads at `http://localhost:8501` and can upload a PDF
- API docs load at `http://localhost:8000/docs`
- Postgres tables (`works`, `attempts`, `jobs`, `artifacts`) populate and MinIO objects exist under `pdf/` and `extract/`

## Notes

- Compose includes GROBID on port 8070; running a separate local GROBID service concurrently will fail with an "Address already in use" bind error.
