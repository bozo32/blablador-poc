# 09.2-01: Corpus + Regression Fixtures

## Work

- Add one or more PDFs to `fixtures/`:
  - `fixtures/choker-header-500.pdf` (or equivalent)
  - optionally: `fixtures/scanned-1.pdf` (for OCR path)
- Add a corpus manifest (text file) listing fixture paths, and expected class tags.

## Verification

1) Bring stack up:

`bash scripts/dev/up.sh`

2) Smoke ingest each fixture and record doc_id:

`bash scripts/dev/smoke_ingest.sh fixtures/choker-header-500.pdf`

3) Trigger primary extraction and confirm failure is reproducible (for the choker):

`curl -4 -sf -X POST http://127.0.0.1:8000/ingest/<doc_id>/extract`

Expected:
- Attempt ends in `failed` or `partial` with a concrete failure reason captured on the attempt/job.
- No missing-pointer failures (i.e., failures are about extraction, not about storage).
