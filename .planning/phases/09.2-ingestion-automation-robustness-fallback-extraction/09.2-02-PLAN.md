# 09.2-02: Fallback Attempt Contract

## Contract

Artifacts (object store, registered in Postgres `artifacts`):

- `pages.jsonl` (page-bounded text + provenance)
  - key: `extract/{work_id}/attempts/{attempt_id}/fallback/pages.jsonl`
  - artifact_type: `fallback.pages.jsonl`
- `body.txt` (joined fallback body text)
  - key: `extract/{work_id}/attempts/{attempt_id}/fallback/body.txt`
  - artifact_type: `fallback.body.txt`
- `refs.json` (fallback bibliography / reference list)
  - key: `extract/{work_id}/attempts/{attempt_id}/fallback/refs.json`
  - artifact_type: `fallback.refs.json`

Quality flags (`attempts.quality_json`):

- `primary.header_failed: bool`
- `primary.refs_only: bool`
- `fallback.used: bool`
- `fallback.ocr_used: bool`
- `fallback.pages_total: int`
- `fallback.pages_ocr: int`
- `fallback.text_layer_coverage: float` (0..1)
- `fallback.ocr_languages: str` (e.g. `"eng"`)

## Verification

1) Run a fallback attempt (manual endpoint or auto-trigger on failure).
2) Confirm:
- artifacts rows exist for the attempt with the expected `artifact_type`
- object store keys exist and can be downloaded
- quality flags are present and stable
