# 09.2-04: PyMuPDF Text-Layer Fallback

## Work

- Create a fallback extractor that:
  - reads the PDF bytes from the object store
  - emits per-page text blocks into `pages.jsonl`
  - emits a joined `body.txt`
  - emits a best-effort `refs.json` (can be minimal in MVP)
  - stores provenance per page (text-layer vs OCR placeholder)

- Trigger fallback.
- Confirm:
  - fallback attempt artifacts exist
  - `GET /ingest/{id}/body` can serve *some* body text even if primary TEI failed
