# 09.3 Verification

Goal: prove Phase 9.3 "spine everywhere" holds under the standard local Compose runtime.

## One-Command Verification

Run:

```bash
scripts/dev/verify_09_3_spine_cutover.sh
```

Optional: also prove no durable `./data/**` is required:

```bash
VERIFY_RM_DATA=1 bash scripts/dev/verify_09_3_spine_cutover.sh
```

If your machine is slow to restart containers, you can extend readiness waits:

```bash
WAIT_SECONDS=180 scripts/dev/verify_09_3_spine_cutover.sh
```

## What This Verifies

- Compose stack is up; API serves `/docs`.
- `POST /dev/wipe` truncates spine tables (Postgres + object store).
- Corpus regression smoke passes (normal mode + deterministic fallback when GROBID is down).
- Evidence selection + judgment persist across `docker compose restart app-api`.
