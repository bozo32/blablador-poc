<objective>
Persist reviewer evidence triage as audit-grade, append-only decision events with idempotency and OCC, projected into fast per-target state, then wire the Streamlit evidence UI to use the server as the source of truth.

Purpose: Make evidence decisions durable/replayable (multi-session safe) and foreshadow multi-user cloud readiness by keeping project_id and created_by_user_id first-class and decisions attributable.
Output: Postgres decision tables + spine store helpers + decision API endpoints + evidence list integration + Streamlit wiring + tests + compose-backed verifier + one manual UI checkpoint.
</objective>

  - columns: event_id bigserial PRIMARY KEY, event_uid text NOT NULL,

    pinned boolean NOT NULL DEFAULT false,
    triage text NOT NULL DEFAULT 'none',
    updated_at timestamptz NOT NULL DEFAULT now(),
