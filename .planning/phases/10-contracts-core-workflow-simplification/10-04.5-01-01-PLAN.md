<task type="auto">
  <name>Task 1: Add multipart source upload endpoint (no local_path)</name>
  <files>backend/main.py, backend/schemas.py</files>
  <action>
Create a new endpoint for uploading a source PDF directly to the backend:

- Add `POST /attachments/upload` that accepts multipart form `file` (PDF) plus optional JSON fields in form params.
- Scope it like existing endpoints:
  - Read `X-Project-Id` header (default to settings default project id)
  - Derive `created_by_user_id` using existing `app_settings.DEFAULT_USER_ID` pattern (no new auth in this plan)
  - Persist both on the created attachment row

Fields:
  - `reference_hint` (json string), `claim_text` (string), `doc_id` (optional), `citation_index` (optional), `target_id` (optional)
- Persist the PDF bytes to object store and create a *global* attachment row with `pdf_object_key` set.
- Return the public attachment status payload (same shape as existing `/attachments` responses).
- Add a request/response schema if needed; keep compatibility with existing `AttachmentResponse`.
- Compute and persist an exact `content_sha256` for dedupe (project-scoped): if an existing *global, unarchived* source attachment in the same project has the same hash, return that attachment instead of creating a new row.

Do NOT:
- require `local_path`
- write to `data/**` as the source of truth
  </action>
