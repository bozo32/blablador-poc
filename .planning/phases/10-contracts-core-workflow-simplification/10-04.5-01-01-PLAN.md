<task type="auto">
  <name>Task 2: Add multipart source upload endpoint (no local_path)</name>
  <files>backend/main.py, backend/schemas.py, backend/attachment_store.py</files>
  <action>
Create a new endpoint for uploading a source PDF directly to the backend:

- Add `POST /attachments/upload` that accepts multipart form `file` (PDF) plus optional JSON fields in form params.
- Require `X-Project-Id` header (400 if missing) by default.
  - Dev-only escape hatch: if env `ALLOW_DEFAULT_PROJECT_ID_FOR_DEV=true`, fallback to settings default project id.
- Derive `created_by_user_id` using existing `app_settings.DEFAULT_USER_ID` pattern.
- Persist the PDF bytes to object store and create a global attachment row with `pdf_object_key` set.
- Compute sha256 of bytes and persist it to `content_sha256`.
- Ensure the returned attachment payload includes `content_sha256` (audit/debug surface).
- Implement dedupe (project-scoped): if an existing global, unarchived source attachment in the same project has the same `content_sha256`, return it.
  </action>
  <verify>

import hashlib, pathlib, sys

p = pathlib.Path(sys.argv[1])
h = hashlib.sha256()
h.update(p.read_bytes())
print(h.hexdigest())
PY "$PDF_PATH")
