## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Attachment pipeline assumed `/tmp` exists**
- **Found during:** Task 3
- **Issue:** Byte-uploaded attachments errored with `No such file or directory: /tmp/attach-...pdf`.
- **Fix:** Ensure the temp PDF parent directory exists before writing.
- **Files modified:** `backend/attachment_pipeline.py`
- **Committed in:** `802b5bc`

**2. [Rule 1 - Bug] Attachment errors were not clearable + retry attempts didn't reset**
- **Found during:** Task 3
- **Issue:** `reset_for_retry()` could not clear `error`, and retries could not run when `attempts == max_attempts`.
- **Fix:** Add an explicit unset sentinel in `update_attachment` so `error=None` clears, and reset `attempts` on retry.
- **Files modified:** `backend/attachment_store.py`
- **Committed in:** `802b5bc`

**3. [Rule 2 - Missing Critical] Upload-triggered processing must not block the API thread**
- **Found during:** Task 3
- **Issue:** Running attachment processing inline caused polling endpoints to time out under load.
- **Fix:** Always use `attachment_pipeline.enqueue_processing()` (thread) for upload-triggered processing.
- **Files modified:** `backend/main.py`
- **Committed in:** `802b5bc`
