# Phase 10-04.5 Plan 01-02: Unified Intake Dropzone + Inbox Summary

**Unified the left-pane upload experience into a single multi-PDF "Drop PDFs" entrypoint with an Intake Inbox that auto-classifies (best-effort), gates unknowns until user choice, and routes citing vs source appropriately.**

## Accomplishments

- Added a top-of-left-pane Intake surface: one dropzone for PDFs and an Inbox list per dropped file.
- Implemented intent gating:
  - `citing` routes to `/ingest` and triggers auto-processing based on UI toggles.
  - `source` routes into the Source upload queue (upload mechanics land in 10-04.5-01-05).
  - `unknown` stays pending until user chooses Citing vs Source (and offers "Attach now" when in a chase context).
- Ensured `/ingest*` calls include `X-Project-Id` via `frontend/ingestion_api.py` helpers.
- Replaced the legacy "Upload documents" expander with guidance to use Intake (single upload entrypoint).
- Added section-height control via per-section sliders (rows shown) remembered per reviewer.
