  <name>Task 1: Enforce X-Project-Id scoping for attachments list/read/mutate</name>
  <files>backend/main.py, backend/attachment_store.py</files>
  <action>
Make Source Inbox project-safe by enforcing project scoping in the backend (not just in the UI):

- Update these endpoints to require/read `X-Project-Id` and enforce it:
  - Require `X-Project-Id` header (400 if missing) by default; allow dev-only fallback via `ALLOW_DEFAULT_PROJECT_ID_FOR_DEV=true`.
  - `GET /attachments` (list): only return attachments where `project_id == header_project_id`.
  - `GET /attachments/{attachment_id}` (read): return 404 if attachment.project_id != header_project_id.
  - `PATCH /attachments/{attachment_id}` (archive/unarchive and placement changes): enforce same project_id.
  - `POST /attachments/{attachment_id}/clone`: enforce same project_id.
  - `POST /attachments/{attachment_id}/promote-ingest`: enforce same project_id.

Enforcement behavior:
- Prefer 404 on mismatch (do not leak existence across projects).

Update `backend/attachment_store.py` helpers if needed so list/get/update/clone can accept a `project_id` filter.
  </action>
  <verify>
PDF_PATH="${PDF_PATH:-corpus/workflow/hicks-chatgpt-is-bullshit.pdf}"
P1="proj-a"; P2="proj-b"

ID2=$(curl -sf -H "X-Project-Id: ${P2}" -F "file=@${PDF_PATH};type=application/pdf" http://localhost:8000/attachments/upload | python -c "import json,sys; print((json.load(sys.stdin).get('attachment') or {}).get('id') or '')")

<task type="auto">
  <name>Task 2: Confirm clone semantics do not mutate the global source</name>
  <files>backend/main.py, backend/attachment_store.py</files>
  <action>
Ensure `/attachments/{id}/clone` creates a new attachment row and never mutates the source attachment’s placement fields.

- The source attachment must remain global/unassigned (no claim_id/doc_id/target_id/citation_index) after cloning.
- The clone should copy `pdf_object_key` and artifacts, and accept placement fields in the request.
- Add/keep a backend-side invariant check so accidental mutation is impossible.
  </action>
  <verify>
P1="proj-a"
PDF_PATH="${PDF_PATH:-corpus/workflow/hicks-chatgpt-is-bullshit.pdf}"
SRC=$(curl -sf -H "X-Project-Id: ${P1}" -F "file=@${PDF_PATH};type=application/pdf" http://localhost:8000/attachments/upload | python -c "import json,sys; print((json.load(sys.stdin).get('attachment') or {}).get('id') or '')")
CL1=$(curl -sf -H "X-Project-Id: ${P1}" -X POST "http://localhost:8000/attachments/${SRC}/clone" -H "Content-Type: application/json" -d '{"doc_id":"doc-a"}' | python -c "import json,sys; print((json.load(sys.stdin).get('attachment') or {}).get('id') or '')")
CL2=$(curl -sf -H "X-Project-Id: ${P1}" -X POST "http://localhost:8000/attachments/${SRC}/clone" -H "Content-Type: application/json" -d '{"doc_id":"doc-b"}' | python -c "import json,sys; print((json.load(sys.stdin).get('attachment') or {}).get('id') or '')")
test "${CL1}" != "${CL2}"

# Source remains unassigned
curl -sf -H "X-Project-Id: ${P1}" "http://localhost:8000/attachments/${SRC}" | python -c "import json,sys; a=(json.load(sys.stdin).get('attachment') or {}); ok=(not a.get('doc_id') and not a.get('claim_id') and not a.get('target_id') and a.get('citation_index') is None); print('ok' if ok else 'bad')" | grep -q ok
  </verify>
  <done>
Clone endpoint is guaranteed to be non-mutating for the source attachment.
  </done>
