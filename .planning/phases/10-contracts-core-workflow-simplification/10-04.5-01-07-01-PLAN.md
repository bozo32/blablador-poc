  <name>Task 1: Require X-Project-Id for all /spans endpoints and scope the store</name>
  <files>backend/main.py</files>
  <action>
Update every `/spans/*` route handler to accept `x_project_id: Optional[str] = Header(None, alias="X-Project-Id")` and scope span-graph operations to that project.

Rules:
- Use `_require_project_id_for_upload(x_project_id)` to enforce: 400 if missing unless `ALLOW_DEFAULT_PROJECT_ID_FOR_DEV=true`.
- Prefer 404 on cross-project mismatch (no existence leaks).
- Do not introduce a "default project" behavior for production paths.

Implementation approach:
- Add a small helper in `backend/main.py` to build a project-scoped store instance:
  - `SpanGraphStore(settings=SimpleNamespace(DEFAULT_PROJECT_ID=project_id))`
- Replace uses of the global `span_graph_store` with the scoped instance for all `/spans/*` endpoints.

Non-exhaustive list (as of this plan draft):
  - `GET /spans/lookup-citation-window`
  - `POST /spans/upsert`
  - `POST /spans/{span_id}/cites`
  - `PUT /spans/{span_id}/cites/{cited_work_id:path}/role`
  - `POST /spans/{span_id}/claim-spans`
  - `GET /spans/{span_id}/status`
  - `GET /spans/{span_id}/bundle`

Verification behavior targets:
- Missing header -> 400 (unless dev fallback enabled)
- Wrong project -> 404 or empty where applicable
