# Phase 10 Plan 07-01: Project-Scoped Spans Summary

**One-liner:** All /spans/* endpoints now require X-Project-Id header and use project-scoped store

## What Was Done

1. **Backend span endpoints project-scoped**
   - Added `X-Project-Id` header requirement to all /spans/* endpoints:
     - GET /spans/lookup-citation-window
     - POST /spans/upsert
     - POST /spans/{span_id}/cites
     - PUT /spans/{span_id}/cites/{cited_work_id}/role
     - POST /spans/{span_id}/claim-spans
     - GET /spans/{span_id}/status
     - GET /spans/{span_id}/bundle
   - Each endpoint now creates a project-scoped SpanGraphStore instance using the project ID

2. **Frontend span helpers updated**
   - Added optional `project_id` parameter to all span API helper functions
   - Helpers now call `_ingest_headers(project_id)` to send X-Project-Id

3. **Tests updated**
   - Added PROJECT_ID constant to test modules
   - All /spans/* API calls now include X-Project-Id header
