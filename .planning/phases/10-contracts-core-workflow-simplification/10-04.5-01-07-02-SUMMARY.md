# Phase 10 Plan 07-02: Opinion Events Layer Summary

**One-liner:** Created append-only opinion events table and API for durable follow/ignore/complete status

## What Was Done

1. **Database schema** - Added `opinion_events` table to migrations with:
   - Fields: project_id, event_id, created_at, actor_uid, owner_uid, kind, target_key
   - Denormalized: doc_id, citation_index, target_id, span_id
   - ACL fields: visibility (private/shared/public), group_id, mode
   - Indexes for common queries

2. **Opinion store** - Created `backend/spine/opinion_events.py`:
   - `append_event()` - Append new opinion events
   - `get_follow_status()` - Get latest follow status for a target
   - `list_follow_by_doc()` - Get follows for a doc (projection)
   - `export_events_ndjson()` / `import_events_ndjson()` - Export/import

3. **API endpoints** - Added `/opinions/*` routes:
   - POST /opinions/events - Append event
   - GET /opinions/follow/by-doc - List follows for document
   - GET /opinions/follow/target - Get follow status for target
   - GET /opinions/events - List recent events

4. **Test stub** - Created `tests/test_opinions_api.py`

## Verification

- Code compiles: `python3 -m compileall -q backend` passes
- New routes registered under /opinions
