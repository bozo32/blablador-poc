# PR-02: Route inventory + explicit route policy map (no behavior changes)

## Objective

Create a deterministic route inventory from `backend/main.py`, classify each endpoint by current scope behavior and target policy class, and document findings for the UID + Project scope lock workstream.

## Constraints

- No backend behavior changes.
- Keep edits restricted to planning/docs/audit artifacts.

## Tasks

1. Add route-audit script to parse `backend/main.py` and emit route policy JSON snapshot.
2. Generate `10-04.5-02-PR-02-ROUTE-POLICY-MAP.json` from the script.
3. Produce `10-04.5-02-PR-02-ROUTE-POLICY-MAP.md` with policy definitions, totals, and classification summary.
4. Add PR-02 findings to `10-04.5-PRUNE-CANDIDATES.md`.
5. Execute staged checks A-F below and capture totals.

## Staged Checks (A-F)

- **A — Script syntax check**
  - `python3 -m py_compile scripts/dev/audit_route_scope_map.py`
- **B — Snapshot generation check**
  - `python3 scripts/dev/audit_route_scope_map.py`
- **C — Snapshot schema sanity check**
  - verify JSON has `route_total`, `routes`, and `totals` keys
- **D — Totals integrity check**
  - verify `route_total == len(routes)` and class totals sum to `route_total`
- **E — Endpoint classification coverage check**
  - verify every route has both `current_scope_class` and `target_policy`
- **F — No behavior-change scope check**
  - `git diff -- backend/main.py` must be empty

## Success Criteria

- Route inventory JSON exists and is reproducible from script.
- Explicit policy map document exists with route and classification totals.
- Prune backlog contains concrete PR-02 findings and follow-up targets.
- `backend/main.py` unchanged.
