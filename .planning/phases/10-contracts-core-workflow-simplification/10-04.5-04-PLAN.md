# 10-04.5-04 Intake Policy Hardening

## Objective

Enforce automatic handling in Intake Drop PDFs with no manual route-choice prompts:

1. Do not show `Route as Citing/Source` controls in Drop PDFs.
2. Auto-route through normal pipeline when placement intent is clear.
3. Route unclear uploads into Stray documents flow (non-blocking, no prompt).
4. Preserve spine-first behavior and matching/retrieval correctness.

## Policy Mapping

- **Clear placement**
  - `intent == "citing"` -> continue `_intake_route_citing(...)`.
  - `intent == "source"` -> continue `_intake_route_source(..., attach_now=False)`.
- **Unclear placement**
  - `intent == "unknown"` -> auto-route to Source Inbox/Stray flow via `_intake_route_source(..., attach_now=False)`.
  - Keep Intake row informational only (status + note), no route buttons.

Why this preserves correctness:

- Unknown docs no longer get optimistic citing ingestion that can create low-confidence extraction/resolution churn.
- Unclear docs are staged in project-shared source queue, where explicit placement/relation is reviewed before graph commitments.

## Exact File Edits

1. `frontend/ui.py`

   A) `render_intake_panel()` -> `_handle_drop()` (around current unknown-intent branch):

   - Change unknown-intent default action from `_intake_route_citing(item_id)` to `_intake_route_source(item_id, attach_now=False)`.
   - Update unknown-item metadata:
     - keep `intent="unknown"`
     - set `routed_intent="source"`
     - set `auto_routed=True`
     - set `override_available=False`
     - set note text to Stray-flow semantics (example: `"Intent unclear; routed to Stray documents for placement review."`).

   B) `render_intake_panel()` item copy:

   - Replace unknown caption text that currently advertises optional overrides with passive policy text:
     - from: `Optional override: route as Source (or re-route as Citing).`
     - to: `Intent unclear; this item was routed to Stray documents for placement.`

   C) `render_intake_panel()` action column:

   - Remove the `if intent == "unknown":` route-choice button block:
     - `Route as Citing`
     - `Route as Source`
     - `Attach now`
   - Keep non-intent actions (near-duplicate controls, details toggle, errors) unchanged.

   D) `render_intake_panel()` empty-state caption:

   - Update text to reflect final policy (no mention of optional override controls).

   E) `render_sources_panel()` empty-state caption:

   - Update copy to reflect intake policy handoff, e.g. unclear uploads surface here automatically.

2. `tests/test_intake_auto_route_phase1.py` (rename intent not required, keep file for continuity)

   - Keep coverage that status refresh follows `routed_intent`.

3. `tests/test_intake_auto_route_phase1.py` (same file, additional case)
