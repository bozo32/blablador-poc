# 10-04.5-07 Walkthrough Fixes (Minimal Safe Changes)

## Goal

Address newly reported walkthrough issues with minimal, low-risk edits while keeping strict scope semantics unchanged:

1. Add a visible UI/API runtime version stamp near the existing scope badge to make stale runtime mismatches obvious.
2. Fix placed-doc edge counters staying stale after scope Apply/Switch by invalidating ledger cache.
3. Classify citation-context missing `X-User-Id` symptoms as stale `app-ui` image behavior and document the required rebuild step.

## Non-Negotiable Constraint

- Do **not** relax or bypass strict scope guards (`X-Project-Id`, `X-User-Id`, reviewer identity requirements).
- No contract change to existing scoped endpoints other than additive observability.
