## Implemented Scope Regression Fixes

1. Backend retrieval endpoint now requires strict scope headers (`X-Project-Id`, `X-User-Id`) and enforces membership before dossier load.
2. Retrieval loader no longer uses default project fallback; retrieval load path now consumes explicit scoped `project_id`.
3. Frontend retrieval callers now require and send strict scope headers for retrieval dossier calls.
4. Retrieval dossier cache keys now include `(project_id, user_id, doc_id, reference_id)`.
5. Scope switch invalidation now clears `retrieval_cache`.
