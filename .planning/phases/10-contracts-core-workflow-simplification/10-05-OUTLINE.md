# 10-05: Demo + Trace Replay

## Objective

Make the POC easily demoable and regression-testable without manual clicking.

## Scope

- Pack a small corpus and a repeatable E2E run script.
- Define a simple event trace format (record + replay) for a review session.

## Success Criteria

- A new machine can run a one-command demo that produces non-empty exports.
- A recorded trace can replay and rebuild the same derived artifacts.
