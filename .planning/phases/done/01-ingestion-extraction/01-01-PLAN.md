<task type="auto">
  <name>Task 1: Add local ingestion storage utilities</name>
  <files>backend/ingestion_store.py, backend/settings.py</files>
  <action>
    Create `backend/ingestion_store.py` with helpers to:
    - Ensure `INGESTION_DIR` exists (default `data/ingestion`).
    - Generate a UUID for each document, save the PDF to `{doc_id}/source.pdf`.
    - Compute SHA256, size, filename, and ISO timestamp for metadata.
    - Write/read `metadata.json` with fields: id, filename, size_bytes, sha256,
      uploaded_at, status, extraction (status/payload placeholder), resolution
      (status/payload placeholder).
    - Provide `create_ingested_document`, `get_ingested_document`,
      `list_ingested_documents`, and `update_ingested_document` helpers.

    Update `backend/settings.py` to add `INGESTION_DIR: Path` with the default
    `Path(__file__).parent.parent / "data" / "ingestion"`.
  </action>
  <verify>python -c "from backend.ingestion_store import create_ingested_document; print(create_ingested_document)"</verify>
  <done>Ingestion storage utilities load and the ingestion root is configurable.</done>
</task>

<task type="auto">
  <name>Task 2: Define ingestion API schemas</name>
  <files>backend/schemas.py</files>
  <action>
    Add Pydantic models for ingestion payloads:
    - `IngestedDocument` (id, filename, size_bytes, sha256, uploaded_at, status,
      extraction, resolution).
    - `IngestListResponse` (documents: List[IngestedDocument]).
    - `IngestUploadResponse` (document: IngestedDocument).
    Keep schema naming consistent with existing models and use optional fields
    for extraction/resolution payloads.
  </action>
  <verify>python -c "from backend import schemas; print(schemas.IngestedDocument.model_json_schema())"</verify>
  <done>Ingestion response models are available for FastAPI endpoints.</done>
</task>

<task type="auto">
  <name>Task 3: Add FastAPI ingestion endpoints</name>
  <files>backend/main.py</files>
  <action>
    Add the following routes using `UploadFile` and the ingestion store helpers:
    - `POST /ingest` accepts a PDF, persists it, and returns `IngestUploadResponse`.
    - `GET /ingest` returns `IngestListResponse` with all documents.
    - `GET /ingest/{doc_id}` returns `IngestedDocument` or 404 if missing.
    Validate content type and file extension, and return `HTTPException` 400 for
    non-PDF uploads.
  </action>
  <verify>uvicorn backend.main:app --reload</verify>
  <done>Upload and list endpoints return ingestion metadata for saved PDFs.</done>
</task>
