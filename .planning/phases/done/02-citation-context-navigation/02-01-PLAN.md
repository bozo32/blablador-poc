  <name>Task 1: Add TEI citation context helpers</name>
  <files>backend/citation_context.py, backend/ingestion_store.py</files>
  <action>
Create `backend/citation_context.py` with helpers that parse TEI XML and return per-callout context (sentence, previous sentence, next sentence, target_id, callout). Use TEI namespace-aware XPath and normalized whitespace like `extraction._text_content` without reusing private functions. Add `get_tei_xml(doc_id, ingestion_dir=None)` to `backend/ingestion_store.py` that loads `extraction/tei.xml` and raises a FileNotFoundError with a clear message when missing. Ensure the context helper gracefully returns `None`/empty values when sentence context cannot be found so the API can surface "context unavailable".
  </action>
  <verify>python - <<'PY'

PY</verify>
  <done>Context helpers can parse TEI XML and ingestion store exposes a TEI loader without import errors.</done>
</task>

<task type="auto">
  <name>Task 2: Implement OpenAlex citation graph helper</name>
  <files>backend/citation_graph.py, backend/settings.py</files>
  <action>
Create `backend/citation_graph.py` with an OpenAlex client that accepts DOI or OpenAlex ID, fetches the root work, and builds a node/edge graph for referenced works and cited-by works. Add an in-memory cache keyed by OpenAlex work ID to reduce repeat calls. Enforce depth and per-level limits, and insert stub nodes labeled "data unavailable" when referenced/cited-by data is empty. Update `backend/settings.py` with `OPENALEX_API_URL` (default https://api.openalex.org/works) and `OPENALEX_API_KEY` fields; include the API key in request params and raise a descriptive RuntimeError on 403/429 so the endpoint can surface a helpful message.
  </action>
  <verify>python - <<'PY'
from backend import citation_graph, settings
print("graph helpers ok", bool(citation_graph) and hasattr(settings.settings, "OPENALEX_API_URL"))
PY</verify>
  <done>OpenAlex client returns graph-ready nodes/edges with caching and settings expose the API key/url.</done>
</task>

<task type="auto">
  <name>Task 3: Wire citation context and graph endpoints</name>
  <files>backend/schemas.py, backend/main.py</files>
  <action>
Add Pydantic response models for citation context and citation graph payloads (nodes, edges, reference metadata) in `backend/schemas.py`. In `backend/main.py`, add `GET /ingest/{doc_id}/citation-context` that accepts `citation_index` and optional `target_id`, loads TEI via `get_tei_xml`, derives the indexed context from `citation_context`, and includes matching bibliography/resolution entries when available. Add `GET /ingest/{doc_id}/citation-graph` that accepts `target_id`, optional `doi`, `depth`, and `max_nodes`, resolves the DOI from extraction/resolution data when not provided, and returns `citation_graph.build_citation_graph` output. Return HTTP 404 for missing documents, missing TEI, or missing DOI, and 502 for OpenAlex request failures.
