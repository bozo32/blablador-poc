  <name>Task 2: Build citation context navigation UI</name>
  <files>frontend/ui.py</files>
  <action>
In `frontend/ui.py`, add a citation context section inside `draw_ingestion_panel()` that splits into two columns: left column lists citation sentences with per-callout buttons (one badge per callout), right column shows the selected callout context and cited work metadata. Use session state to track the selected citation index/target and replace the right-pane content on selection. Call `get_citation_context` to render the sentence plus adjacent sentences, with a skeleton placeholder while loading and an inline "context unavailable" message when empty. Add a "Follow citation" action that reveals bibliography/resolution data from the API response. Add controls for depth and node caps, then call `get_citation_graph` and render with `graphviz.Digraph` + `st.graphviz_chart`, showing stub nodes labeled "data unavailable" and a fallback "no data" message when the graph is empty. Surface API failures with `st.toast` (or `st.error` fallback) and provide a retry button that re-runs the last request.
