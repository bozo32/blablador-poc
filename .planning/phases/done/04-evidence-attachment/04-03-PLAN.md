Include single automatic retry before surfacing failure per CONTEXT.
- Extend `backend/schemas.py` with `AttachmentStatus`, `AttachmentTimelineEvent`, `AttachmentResponse` models for API serialization.
- Update `backend/main.py` to add `POST /claims/{claim_id}/attachments` (accepts metadata + file path from UI) and `GET /claims/{claim_id}/attachments/status` (returns queue for that claim) plus `GET /attachments/{attachment_id}` for global polling. Use FastAPI BackgroundTasks to run `process_attachment` asynchronously and ensure statuses persist even if the server restarts.
- Update `backend/ingestion_store.py` if needed to expose helper methods for attachment metadata read/write (e.g., `load_claim_metadata`).
