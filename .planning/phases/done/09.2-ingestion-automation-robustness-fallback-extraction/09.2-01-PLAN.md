# 09.2-01: Corpus + Regression Fixtures

## Work

- Keep `fixtures/` small and redistributable.
- Provide a deterministic choker scenario by stopping grobid for a run.
- Include a scanned-ish OCR fixture:
  - `fixtures/scanned-1.pdf`
  - generated deterministically:
    - `bash scripts/dev/gen_scanned_fixture.sh fixtures/scanned-1.pdf`
- Add a corpus manifest (text file) listing fixture paths, and expected class tags.
  - Default: `fixtures/corpus-09.2.txt`

## Verification

1) Bring stack up:

`bash scripts/dev/up.sh`

2) Smoke ingest each fixture and record doc_id:

Run the whole corpus:

`bash scripts/dev/smoke_corpus.sh fixtures/corpus-09.2.txt`

Note: until we have a redistributable "real" choker PDF committed, we treat
"GROBID unavailable" as a deterministic choker scenario for verifying that
fallback artifacts and attempt quality flags are produced.

3) Deterministic choker scenario (GROBID down):

`bash scripts/dev/with_grobid_down.sh -- bash scripts/dev/smoke_corpus.sh fixtures/corpus-09.2.txt`

Expected:
- Attempt ends in `partial` with fallback artifacts + quality flags captured on the attempt/job.
- No missing-pointer failures (i.e., failures are about extraction, not about storage).
